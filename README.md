# Telhado da casa

Desenhos técnicos da cobertura de duas águas, cotados com as medidas reais.

## Medidas

| Elemento | Valor |
| --- | --- |
| Comprimento | 12,00 m |
| Largura | 6,35 m |
| Espessura das paredes | 0,30 m |
| Vão interior (largura) | 5,75 m |
| Vão interior (comprimento) | 11,40 m |
| Cume em relação ao beiral | 1,80 m |
| Pendente | ≈ 29,6° |
| Comprimento de cada água | ≈ 3,65 m |
| Beiral | ≈ 0,25 m |
| Tipologia | Duas águas |
